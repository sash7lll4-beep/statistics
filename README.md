# Тренажёр — магистратура

Приложение для подготовки по трём предметам:

- Анализ данных на Python
- Статистика и машинное обучение
- Базы данных

В каждом предмете пять вкладок: конспект, тест, задачи на счёт, код и прогресс. Приложение устанавливается на телефон и компьютер и работает без интернета.

## Как опубликовать на GitHub Pages (один раз)

1. Зайди на github.com. Нажми **New repository**, назови его, например, `trainer`. Выбери **Public** и нажми **Create repository**.
2. На странице нового репозитория нажми **uploading an existing file**.
3. Открой в Finder папку `trainer-app` и выдели всё её содержимое: `index.html`, `app.css`, `manifest.webmanifest`, `sw.js`, `.nojekyll`, папки `js` и `icons`.
   - Перетаскивай именно содержимое, а не саму папку.
   - Чтобы увидеть скрытый `.nojekyll`, нажми ⌘⇧. в Finder.
4. Перетащи выделенное в окно браузера и нажми **Commit changes**.
5. Открой **Settings → Pages**. В разделе **Branch** выбери `main` и `/ (root)`, нажми **Save**.
6. Подожди 1–2 минуты. Адрес появится вверху той же страницы, например `https://<твой-логин>.github.io/trainer/`.

## Как установить

- **iPhone (Safari):** открой адрес, нажми «Поделиться», потом «На экран „Домой“».
- **Android (Chrome):** открой адрес, нажми меню ⋮, потом «Установить приложение».
- **Mac:**
  - Chrome: значок установки справа в адресной строке.
  - Safari: «Файл» → «Добавить в Dock».
- **Windows (Chrome или Edge):** значок установки в адресной строке.

После первого открытия приложение работает и без интернета.

## Прогресс

Прогресс хранится отдельно на каждом устройстве и отдельно по каждому предмету.

**Перенести на другое устройство:**
1. На старом устройстве открой «Прогресс» → «Перенести прогресс на другое устройство» → «Скопировать код».
2. Вставь код на новом устройстве в том же разделе.

**Перенести из старого тренажёра на claude.ai:** скопируй код в нём так же и вставь его в предмете «Анализ данных на Python».

## Как обновить

1. Поменяй файлы.
2. В `sw.js` увеличь `VERSION` (например, `'v1'` → `'v2'`), иначе установленное приложение долго будет показывать старую копию.
3. Загрузи изменённые файлы в репозиторий так же, через **Add file → Upload files**.

## Как добавить предмет

1. Создай `js/subjects/<id>.js` по образцу существующих. Внутри — вызов `addSubject({ id, name, short, sub, icon, codeLede, TOPICS, NOTES, QUIZ, GEN, CODE })`.
2. Подключи его в `index.html` перед `js/app.js`.
3. Добавь его в список `SHELL` в `sw.js`.

Формат данных:

- **`QUIZ`:** `[тема, вопрос, [правильный, неправильные…], 0, объяснение]`. Варианты перемешиваются при показе.
- **`GEN`:** функции, которые каждый раз генерируют новую задачу: `{ text, answer, sol }` или `{ type: 'choice', options, answer }`.
- **`CODE`:** упражнения четырёх видов:
  - `fill`: пропуски `[1]`;
  - `out`: «что выведет»;
  - `bug`: «найди ошибку»;
  - `line`: «напиши сам», проверка по ключевым фрагментам `need`.
- **`ci: true`:** сравнение без учёта регистра (для SQL).
